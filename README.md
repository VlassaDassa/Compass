# Компас

База знаний IT-поддержки с редактируемой 3D-картой офиса, сотрудниками, статьями и PostgreSQL. Начальное содержимое вымышленное; рабочие данные можно перенести через настройки.

**Развёртывание на VPS:** [пошаговая инструкция для compass.vlassadassa.ru](docs/VPS.md), путь `/srv/compass/repo`, Node.js на `127.0.0.1:4180`, отдельный PostgreSQL на `127.0.0.1:55432`, Caddy и systemd. Сначала `npm run setup:vps`; генератор создаёт закрытый `.env` со случайными паролями и сохраняет существующие настройки.

Карта использует Three.js/WebGL и ортографическую камеру. Каждый корпус — отдельная площадка на общей карте; все корпуса видны одновременно. Один переключатель этажа действует на все корпуса. Если этажа ещё нет, площадка остаётся видимой; нужный этаж можно добавить в выбранном корпусе. Координаты, оборудование и назначения хранятся отдельно в каждом корпусе. Поддерживаются объёмные лестницы, перенос, размер и контекстное меню; инструменты добавления находятся в нижней строке карты.

«Настройки → Общее → Цвет и движение» позволяет задать десять цветов интерфейса и фона через палитру или HEX, настроить графику, зерно и инерцию прокрутки. Изменения видны сразу и сохраняются по кнопке. Для точных цветов отключите «Автоконтраст»; читаемая кнопка «Сбросить тему» доступна и при неудачной комбинации. Стандартная тема — почти чёрный графит с непрозрачными панелями, нейтральными полями и приглушённой графикой. Прежняя стандартная фиолетовая палитра обновляется автоматически, вручную выбранные цвета сохраняются.

Проверки: `npm run check`, `npm test`. `npm run verify:integration` создаёт отдельную временную БД, проверяет API и браузер, затем удаляет только свою тестовую БД. Для этой команды нужны локальный PostgreSQL, право создания тестовой БД и Chromium (`COMPASS_CHROMIUM`, по умолчанию `/usr/bin/chromium`).

## Запуск

Нужен Node.js 22+.

```sh
npm install
npm run build
npm run dev
```

Открыть `http://127.0.0.1:4173`. Готовый `dist/` можно раздавать любым статическим веб-сервером. После сборки приложение не требует Node.js в браузере. Все библиотеки и шрифты находятся в проекте; внешние запросы для работы интерфейса не нужны.

## Локальная PostgreSQL

Для общей базы создайте `.env` со случайными паролями, запустите PostgreSQL и задайте `COMPASS_DATABASE_URL`. Самый простой вариант — Docker:

```sh
npm run setup:vps
docker compose up -d --wait postgres
npm run dev
```

Приложение сохраняет всё состояние рабочей области в PostgreSQL через сервер Compass. Сервер сообщает об ошибке при недоступности БД. Опубликованная статическая версия без Node.js использует хранилище браузера; её данные можно перенести на VPS через файл рабочего пространства. Генератор создаёт production-настройки для указанного домена; для разработки задайте `NODE_ENV=development` и `COMPASS_PUBLIC_URL=http://127.0.0.1:4180` в `.env`.

## ИИ-провайдер

В «Настройки → ИИ-помощник» администратор может выбрать GigaChat или любой OpenAI-compatible API, указать модель, адрес и ключ. Ключ шифруется на сервере значением `COMPASS_SECRET` и не возвращается в браузер. Рекомендуемый первый вариант для России — GigaChat; для другого сервиса достаточно заменить провайдера и credentials в этой форме.

## Что работает

- Главная страница, категории, полнотекстовый поиск по заголовкам, меткам и содержимому, фильтр отдела и сортировка.
- Чтение инструкций, оглавление, избранное, копирование ссылки, даты вступления изменений в силу.
- Визуальный редактор Tiptap: заголовки, жирный/курсив/подчёркнутый/зачёркнутый текст, списки и вложенные чек-листы, цитаты, ссылки, таблицы с добавлением/удалением строк и столбцов, блоки кода, разделители, отмена/повтор.
- Картинки: выбор файла, вставка из буфера, перетаскивание. PNG/JPEG/WebP/GIF до 12 МБ на файл. Статические изображения оптимизируются до 1800 px и WebP, а небольшие GIF сохраняют анимацию. Данные остаются в локальном хранилище.
- Автосохранение черновиков, восстановление после перезагрузки, предпросмотр, предупреждение о похожем заголовке, публикация и редактирование.
- История версий с просмотром старого текста и восстановлением в новую версию; старые записи сохраняются.
- Демонстрационный справочник сотрудников, поиск, фильтр отдела, переход на интерактивный план этажа, карточка оборудования места.
- Справочник дополняется email, личным телефоном и демонстрационным паролем: раскрытие по кнопке, автоматическое скрытие через 20 секунд, при уходе со страницы и закрытии карточки. Карточки сотрудников редактируются.
- Заметки сотрудников до 5000 символов: правая кнопка по карточке или занятому месту на карте, кнопка «⋯» на телефоне. В меню доступны заметка, редактирование и переход на карту. Заметки сохраняются в карточках, доступны в поиске и экспорте; видна дата обновления.
- Свободный редактор карты: прямоугольные зоны с любыми названиями и шестью спокойными оттенками, без обязательных типов помещений. Режим «Без стен» позволяет соединять и пересекать прямоугольники для коридоров и открытых площадок. План, зоны и предметы растягиваются за любой край или угол; точные размеры доступны в форме.
- Палитра предметов: двери, окна, отдельные принтеры с IP и моделью, столы, шкафы, растения, диваны и произвольные ориентиры. У предмета есть название, описание, размеры, цвет, поворот; размещение доступно в любой зоне и прямо на плане. Предметы перетаскиваются с привязкой к сетке.
- Контекстное меню объектов и зон: редактирование, поворот, добавление содержимого, удаление. Доступно 30 шагов отмены/повтора в текущей вкладке (Ctrl Z / Ctrl Shift Z). Удаление зоны освобождает назначения рабочих мест; сотрудники остаются в справочнике. Отмена возвращает зону вместе с оборудованием и назначениями.
- В режиме «Редактировать карту» рабочие столы перетаскиваются внутри кабинета с привязкой к сетке 10 единиц. Shift ограничивает движение одной осью; стрелки сдвигают выбранный стол на 1 единицу, Shift + стрелки — на 10. Пробел с перетаскиванием двигает схему. Выход за кабинет и пересечения столов не сохраняются; оборудование и назначенный сотрудник остаются у места.
- В рабочем месте сохраняются IP телефона, имя/IP/модель принтера, имя ПК и внутренний телефон. Поля IP проверяются перед сохранением.
- На телефоне карта поддерживает перемещение, масштабирование двумя пальцами, кнопки масштаба, выбор кабинета, поиск и список рабочих мест. Карточка выбранного места открывается снизу. Убран видимый скроллбар; блокировка фоновой прокрутки в модальных окнах не меняет ширину страницы.
- Пользовательские ссылки. Демо управления пользователями и ролями, без отправки приглашений.
- Контрастная тёмная тема: графитовые поверхности, светлый текст и цветные акценты во всех разделах, редакторе и модальных окнах.
- Более яркая палитра: золотые кнопки, мятные, сиреневые, терракотовые и небесные акценты на тёмных поверхностях.
- Справочник сотрудников независим от карты. В карточке без места показана отметка «Нет на карте». Можно добавлять сотрудников, отмечать увольнение с датой, освобождать место, возвращать в действующие и полностью удалять карточку после ввода её имени. Удаление сотрудника сохраняет оборудование места и очищает его назначение.
- Копирование одним кликом: контакты, IP, имена ПК и принтеров, пароли, сетевые пути и блоки кода. У скрытого значения копирование не раскрывает текст на странице.
- Инструменты → Хранилище: универсальные записи с описанием и до 20 подписанных полей (URL, адрес, логин, путь, произвольный текст). Отдельные поля можно скрывать; раскрытие автоматически закрывается через 20 секунд и при уходе со страницы. Поиск не использует скрытые значения. Удалённые записи можно восстановить; хранятся 20 последних удалений.
- Экспорт статей, изображений, версий, черновиков, пользователей и настроек в JSON.

## Границы текущей реализации

**Это локальный прототип, а не готовая корпоративная система.** IndexedDB хранит данные отдельно для каждого браузера и origin. Нет общей серверной базы, синхронизации между устройствами, настоящего входа и серверного контроля ролей. Статический хостинг Sites имеет собственный приватный доступ владельца, который не является корпоративной авторизацией сотрудников.

Демо пользователей не создаёт учётных записей и не выдаёт права. Текущий профиль администратора фиксирован. Примеры инструкций нельзя считать утверждёнными регламентами организации. Не вносите конфиденциальные данные в размещённую демонстрацию.

ИИ не подключён. Поле вопроса выполняет локальный поиск статей, а проверка дубликатов сравнивает слова в заголовках. Настройка внешнего/локального провайдера сохраняет выбор для следующего этапа, но не отправляет запросов. Итилиум, AD, каталог сотрудников и хранилище паролей обозначены отдельными заглушками.

Файлы и резервная копия браузера не заменяют серверное резервное копирование. После удаления данных браузера локальные статьи пропадут. Экспортируйте значимые материалы через Настройки → Общее → Экспорт.

Демонстрационные пароли хранятся отдельно от данных карточек в локальном IndexedDB и исключены из JSON-экспорта, поиска, ссылок и HTML до раскрытия. Маскирование не является шифрованием или проверкой прав. Для реальных секретов требуется корпоративное хранилище и серверная авторизация; этот прототип для них не предназначен.

Это относится и к новому разделу «Хранилище»: его скрытые поля остаются локальными демонстрационными данными, а не защищённым менеджером секретов. Экспорт версии 3 содержит записи хранилища с пустыми значениями скрытых полей и пометкой `redacted`; корзина хранилища не экспортируется. Копирование по явному нажатию передаёт выбранное значение в системный буфер обмена.

## Следующий этап: внутренняя установка

См. [docs/architecture.md](docs/architecture.md), [docs/schema.sql](docs/schema.sql), [src/integration-contracts.ts](src/integration-contracts.ts).

Перед переносом реальных данных нужен внутренний сервер с HTTPS, общей БД, авторизацией, резервными копиями и журналом изменений. Серверный адаптер заменяет функции в `dist/store.js`; пользовательский интерфейс сохраняется. Пароли следует получать из корпоративного менеджера секретов через отдельный API; хранить их в статьях, экспорте, HTML, браузере или векторном индексе нельзя.

## Структура

`dist/app.js` — маршруты и интерфейс; `dist/store.js` — локальный репозиторий и очистка HTML; `dist/data.js` — вымышленные примеры; `dist/style.css` — адаптивный дизайн; `src/editor.js` — редактор Tiptap; `build.mjs` — сборка редактора и копирование шрифтов.

`dist/office.js` — справочник и подключение редактора карты; `dist/office-model.js` — геометрия, размещение и перенос сотрудников; `dist/map-gestures.js` — перетаскивание и масштабирование; `dist/office.css` — карта, карточки и стабильная прокрутка; `dist/theme.css` — тёмная тема. `npm test` проверяет расширение плана, пересечения, размещение и перемещение мест, сохранение оборудования, перенос сотрудника и валидацию IP. Обновление структуры локального хранилища сохраняет ранее созданные статьи и черновики.

`dist/layout-editor.js` и `dist/map-scene.js` — свободный редактор и SVG-сцена; `dist/layout-editor.css` — новые инструменты и цветовая палитра; `dist/people-model.js` — статусы и удаление сотрудников; `dist/vault.js` / `dist/vault-model.js` — интерфейс и модель универсального хранилища; `dist/copy-utils.js` — копирование. Миграция карты в версию 2 сохраняет существующие координаты, оборудование, назначения, статьи и заметки; декоративные стол и принтер становятся редактируемыми объектами.

В проекте нет аналитики, трекеров и внешних запросов к ИИ. Переходы по добавленным вами ссылкам открывают соответствующие ресурсы отдельно.

Карта использует спокойные нейтральные материалы и SVG-мебель с тенями: рабочие места, двери, окна, принтеры и другие предметы. В редакторе вся граница каждого объекта доступна для растягивания: четыре стороны и четыре угла. Мебель и оборудование всегда сохраняют пропорции, SVG вписывается в размер без искажений; зоны и план свободно меняются за сторону и пропорционально за угол. Растягивание комнаты слева или сверху сохраняет мировое положение мебели. При расширении плана слева и сверху координаты содержимого сдвигаются без скачка изображения. Размеры рабочих мест сохраняются рядом с оборудованием, старые записи используют размер 120 × 75. Изменения поддерживают отмену/повтор и проверку границ. `dist/map-art.js` хранит SVG-материалы и мебель, `dist/map-resize.js` — расчёт пропорций и размеров, `dist/map-realism.css` — оформление карты.

Редактор карты поддерживает поворот мест, предметов и зон на 90°; зона поворачивается вместе с мебелью. Ctrl C / Ctrl V и команды контекстного меню копируют отдельные предметы, рабочие места или зоны с содержимым. У копий мест новые ID и номера, назначения сотрудников остаются у оригиналов. Буфер объектов действует внутри вкладки; ввод и копирование текста в полях не перехватываются. Delete / Backspace удаляют выбранный элемент независимо от фокуса после перерисовки; удержание клавиши не удаляет следующие элементы. Этаж можно удалить вместе с планом, в том числе последний, и восстановить через отмену. Справочник сотрудников при этом сохраняется. Перемещение зон сохраняет камеру. Предметы расположены над стенами, для выбранных небольших предметов есть отдельный центральный захват; растягивание мебели включается после выбора. Примыкающий коридор автоматически убирает общий участок стены; при перемещении или удалении прохода стена возвращается. `map-actions.js` реализует поворот, копирование и удаление этажей; `map-walls.js` вычисляет проёмы.
